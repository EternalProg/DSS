СППР (Система підтримки прийняття рішень)

Вибір платформи для дистанційного навчання

Односторінковий інтерфейс для демонстрації повного циклу: збір експертних даних, формування моделі, правила та аналіз результатів.

Навігація

4 екрани: Експертиза, Модель і Дані, Правила, Результати.

Екран 1 Екран 2 Екран 3 Екран 4

Екран 1. Експертиза

Імпорт CSV (Google Forms export) з оцінками/ранжуванням. Після імпорту експерти створюються автоматично (k=1 за замовчуванням).

Імпорт CSV (оцінки експертів)

Цей імпорт заповнює експертів + числові оцінки (1–10) + ранжування альтернатив (1–4). Дані використовуються для узгодження E7/E1 та інших розрахунків.

Голосування за ваги критеріїв

Окремий CSV (не з Google Forms): експерт + значення для C1..Cn (ранги або оцінки). Після імпорту система оновить ваги критеріїв.

Метод голосування

Тріадні оцінки (E2)

Окремий CSV для E2: один рядок = одна тріада (expert + alternative + criterion + optimistic/realistic/pessimistic). Без цього E2 не рахується.

Узгодження експертних оцінок

Тут CSV не імпортується: методи беруть дані з попередніх імпортів. Якщо увімкнути "Оновити таблицю ОЦІНОК", узгоджені значення буде записано в матрицю.

Методи узгодження

Ручне введення (опціонально)

Якщо CSV недоступний, можна заповнити базові дані моделі на екрані 2.

Порада: спочатку створіть альтернативи та критерії, потім імпортуйте CSV.

Екран 2. Модель та Дані

Альтернативи, критерії, матриця оцінок та ваги критеріїв.

Альтернативи

Платформи дистанційного навчання для порівняння.

Критерії

Фактори, за якими оцінюються альтернативи.

Матриця оцінок

Заповнення матриці оцінювання альтернатив. Подвійний клік на комірку для редагування.

Ваги критеріїв

Встановіть важливість кожного критерію (1-10).

Екран 3. Експертна логіка (Правила)

Пороги/обмеження та IF-THEN правила.

Пороги

Напр., мінімальний рівень безпеки або максимальна вартість.

Для maximize поріг означає x ≥ поріг, для minimize — x ≤ поріг.

IF-THEN правила

Логіка рекомендацій, пояснення та фільтрація альтернатив.
